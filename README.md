# Villanova Track & Field Rankings Tool

Internal coaching tool for tracking Villanova T&F athlete rankings, built on TFRRS data.

## Features

- **By Event** — all Villanova athletes per event with conference, regional, and national rankings
- **Composite / Chop Order** — single ranked list across all athletes by WA points, sortable by conf/regional/national rank
- **Athlete Profiles** — season progression charts, meet-by-meet results, year-over-year mark comparison
- **PDF Export** — print-ready roster PDF with composite rankings and per-event breakdowns
- **Bubble Reference** — historical NCAA championship qualifying marks per event

## Stack

Python · Streamlit · TFRRS scraper · ReportLab · Plotly

## Deployment

Deployed via Streamlit Cloud. Main file: `streamlit_app.py`.
